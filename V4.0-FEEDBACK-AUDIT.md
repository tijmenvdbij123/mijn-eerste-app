# Version 4.0 — point-by-point feedback implementation audit

Source: user's notes on Version 3.6. The intent is to track *every* requested game, rule, difficulty and mode, not merely list files that were touched.

## Overall: two separate new categories

**Implemented.** Added `New Topic Trivia` (`topic-trivia`) and `Party Challenges (New)` (`party-challenges`), both separate from every pre-existing game category. Renamed existing `Trivia` category to `Classic & General Trivia`, without moving the three classic trivia games. Both new categories are on by default in setup, and can independently be disabled.

## Eight new topic trivia games — one new category

**Implemented:** Trivia: History, Trivia: Sports & Athletics, Trivia: Movies & TV, Trivia: Culture, Trivia: Geography, Trivia: Science & Nature, Trivia: Arts & Literature, Trivia: Music.

- Same eight proficiency levels as the existing app: Beginner → Grandmaster.
- For **each topic and each level**: 40 distinctly worded questions = eight cards of five questions. All cards have a numbered answer key. Across eight topics and eight levels, this yields **2,560 question placements**.
- Generation design: 20 curated factual records per level, each with two different questions and answers. Beginning at Novice, a level reuses ten factual records from the preceding level and combines them with ten new ones. Thus each topic/level contains 40 non-identical question texts, but the 2,560 placements **are not claimed to represent 2,560 unrelated facts or globally nonrepeated questions**. If you want 40 unrelated facts at every level, that requires another content expansion.
- **Gameplay interpretation** (not separately prescribed): Each new topic quiz is a 150-second 1v1/team-vs-team trivia **battle** with five questions per side at that side's proficiency. The active side scores only if it gets more correct than its opponent; ties block the point. This makes the new quizzes useful in both Team Battles and Solo Showdown.
- A defender on another difficulty gets a separate level-adjusted card. The answer keys are kept hidden until the clock runs out or the host confirms that the attempt has finished.
- Detailed question text and answers are supplied in `V4.0-NEW-GAMES-CATALOG.md`.

## Stare Battle Without Blinking

**Implemented:** 1v1 in both Team Battles and Solo Showdown; no timer. Any proficiency level can face any level. First to blink loses. If there is a neutral third team, that team serves as judge. If there is no neutral team, both opponents agree fairly on the result; disputed rounds can be replayed. The active team earns a point only if its representative wins.

## Make the Other Laugh in 1 Minute

**Implemented:** Exactly 60 seconds, always 1v1 in both game formats, all levels compatible. Facial expressions, speech, jokes, funny voices and acting are permitted. The active player gets the point if the defender laughs within the minute. No touching or unsafe stunts.

## Rebus / Secret Word

**Implemented:** Rebus is a text-card trivia-letter puzzle (sometimes called a word-extraction puzzle): answer trivia questions, take the indicated numbered letter of each answer, and concatenate letters into an easy secret word.

- **Beginner excluded** from selection, defending and difficulty dropdown.
- **2 minutes 30 seconds** to solve. Start timer before showing the same clue card to both sides.
- **All clues come from exactly one level BELOW the active difficulty**, e.g. Amateur trivia for Intermediate Rebus. Letter positions are checked against their actual answers; single-word trivia answers avoid ambiguous spacing.
- **Team Battles:** app offers 1v1 or 2v2 (team battle). In 2v2 both teams select exactly two players physically; if a team contains three players, the third must sit out, not assist. **Solo Showdown:** only 1v1.
- **First correct final-word guess wins. Any side that makes its first final-word guess incorrectly immediately loses and the other side wins.** Each side gets just one final guess. Only if the active side wins is one point awarded; a defender victory gives no point. If neither guesses in time, no one scores.
- Exactly 3, 4, 4, 5, 5, 6 or 7 questions and letters for Novice, Amateur, Intermediate, Competent, Skilled, Advanced or Grandmaster respectively. There are eight valid Rebus cards per eligible level (56 total).
- Interpretation: The feedback refers to 'Rebus' as questions that spell a secret word, so this implementation uses *letter extraction* rather than picture/emoji rebuses. The app does not electronically collect guesses: players answer aloud and the host uses the ordinary scoring controls. It does show answer keys after finishing for adjudication.

## Arm Wrestling

**Implemented:** Always a 1v1 matchup in both formats. There is no time limit. Only the active player's victory awards a point; a defending player victory awards no point. A safety opt-out and rules for a stable table, elbows supported, avoiding twisting and stopping on discomfort are included.

## Riddle Round

**Implemented:** 2:30 timer; Beginner excluded. New level-specific sets of riddles and answer keys, with five randomized card variants per eligible difficulty level.

| Level | Riddles displayed | Correct needed |
|---|---:|---:|
| Beginner | Not available | — |
| Novice | 2 (very simple) | 1 |
| Amateur | 3 (simple) | 2 |
| Intermediate | 3 (more difficult) | 2 |
| Competent | 3 (more difficult) | 2 |
| Skilled | 3 (more difficult) | 2 |
| Advanced | 4 (harder) | 3 |
| Grandmaster | 5 (hardest) | 4 |

**Gameplay interpretation:** The notes do not specify a 1v1 or team battle for riddles, so it is a **cooperative team task** in Team Battles (active teammates work together) and **solo challenge** in Solo Showdown. Another player/team checks answers after the timer, and only the active side can score.

## Preserved V3.6 features and tests

- All **24 older games** and their category assignments remain in Team Battles.
- All **20 older Solo Showdown games** remain, with the same four excluded cooperative games.
- Team Battles has **37** total minigames; Solo Showdown has **33** total minigames.
- Existing 3.6 rules for Category Flood, Word Recall's 90-second writing phase, Clock Duel's Amateur minimum and Rock-Paper-Scissors decisive throws remain unchanged.
- The V4.0 code uses the new session protocol and browser storage version to avoid applying older sessions/round data to different game definitions.
- Added automated checks for trivia counts and distinct questions, puzzle extraction letters and source levels, timer lengths, level exclusions, open matchmaking, new-game UI rendering and scoring. Manual multiplayer/browser playtesting is still advisable.

## Ambiguities / decisions made without blocking the release

1. **Topic trivia scoring:** implemented as five-question battles, because no specific win rule was given for the eight new trivia games.
2. **Riddle round:** interpreted as a cooperative team task and a solo challenge, since no competition format was specified.
3. **Rebus type:** interpreted as a word revealed via trivia-answer letter extraction, rather than a visual picture riddle.
4. **Trivia question diversity:** 40 distinct question prompts per topic/level, generated from 20 pairs of factual prompts; some knowledge facts are repeated from a nearby level, as documented above.
5. **Arm wrestling:** no clock specified, so it is untimed with an opt-out for safety.

These are explicit decisions, not incomplete tasks.
