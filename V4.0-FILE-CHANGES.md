# Version 4.0 — changed and new files relative to Version 3.6

## Modified website source

- `index.html` — V4.0 title and metadata
- `src/app.js` — new trivia card rendering, level-specific opponent content, game instructions, timers, 2v2 participants, judge notices, hidden answers with confirmed finish, new-game counts, storage/version migration
- `src/engine.js` — game count, proficiency restrictions, packed content, state V4.0
- `src/games.js` — new categories and 13 new games (eight topic-trivia games + five party challenges)
- `src/levels.js` — open matchmaking for no-age-limit games and new trivia
- `src/single-mode.js` — the new games' solo-format eligibility and instructions
- `src/session.js` — V4.0 multiplayer protocol/version
- `src/packs/index.js` — register new topic and challenge packs
- `README.md` — V4.0 setup and mechanics
- `tests/v3.6.test.mjs` — adapt original regression tests to the expanded game catalog and version

## Newly added source files

- `src/packs/topic-trivia.js` — 40-question-per-level card generation and public topic packs
- `src/packs/topic-trivia-seed-parser.js` — validates trivia question seed formats
- `src/packs/topic-trivia-seeds-a.js` — history, geography and sports questions
- `src/packs/topic-trivia-seeds-b.js` — movies/TV and culture questions
- `src/packs/topic-trivia-seeds-c.js` — science/nature and arts/literature questions
- `src/packs/topic-trivia-seeds-d.js` — music questions
- `src/packs/new-challenges.js` — Rebus and Riddle level-specific prompts and keys
- `tests/v4.0.test.mjs` — new gameplay/content/rendering tests
- `V4.0-FEEDBACK-AUDIT.md` — point-by-point implementation record
- `V4.0-FILE-CHANGES.md` — this file
- `V4.0-NEW-GAMES-CATALOG.md` — full new trivia, Rebus and Riddle review catalog

## Intentionally unchanged

- `assets/style.css`
- Original card/question data in `src/packs/acting.js`, `creative.js`, `drawing.js`, `knowledge.js`, `words-memory.js`, `trivia-v33-additions.js`, `trivia-v34-rules.js`
- `tests/v3.6-ui.test.mjs`
- Earlier release audit docs included for reference.

## GitHub Pages deployment

It is safest to upload **the entire extracted V4.0 ZIP**, preserving all relative paths. Uploading only the changed JavaScript modules without the new `src/packs/` files will cause module imports to fail and leave the website blank.
