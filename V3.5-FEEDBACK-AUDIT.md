# Version 3.5 — detailed feedback implementation audit

This file translates each requested V3.5 change into visible behavior. The
*original* 24-game Team Battles experience remains available alongside the
new one-player-per-team format.

## Overall requirements

| Request | Result |
| --- | --- |
| Button on home screen | Two choices: **Team Battles** (original) and **Solo Showdown** (new). |
| Every team has exactly one player | Solo Showdown setup has one name and one proficiency level per player/team; no teammate fields. |
| Up to three players / teams | Solo Showdown supports **2–3 players**; 2 is the minimum because the game requires competing teams. The Add Player button stops at 3. |
| Same game-card packages | Both formats use the existing proficiency-specific V3.4 content datasets; V3.5 changes rules, not the question bank. |
| All suitable original games | Solo Showdown has **20** games; Team Battles keeps **all 24**. |
| Score restriction | Only the currently playing person can earn the turn's single point. A defender only blocks it. The turn then rotates through all players. |
| Matchup selection | 1v1 opponents are either app assigned or chosen by the current player, subject to level compatibility. |
| Multiplayer sessions | The same host-led, up-to-five-device sessions work with both formats. V3.5 host/guest clients must use the same version. |

## Each game in Solo Showdown

| # | Game | Adapted format and point rule |
| --- | --- | --- |
| 1 | Category Flood | **Two versions**: solo reach the level-based fixed number of items; 1v1 both write as many unique valid items as possible, and the active player must have **more**. In both cases start the 150-second clock before revealing. |
| 2 | Rhyme Rally | **1v1** starting with the card word and alternating in five seconds per reply; active player scores if defender fails first. No main clock. |
| 3 | Last Letter Duel | **1v1**, alternating from the last letter, with five seconds per reply; active player scores if defender fails first. No main clock. |
| 4 | Shape Copy | **1v1**: both competitors view the original within the card's proficiency-based limit and make their own copies. More correctly reproduced details wins; ties block points. |
| 5 | Word Recall Battle | **1v1**: both memorize the **same** list for 25 seconds, then write recalled words for 60. More correctly recalled unique words wins; ties block points. The restart-confirmation button remains. |
| 6 | Shopping Basket | **1v1** alternating the complete shopping list; active player scores only if defender makes the first memory/order mistake. No main clock. |
| 7 | Digit Memory | **Two versions**: solo reproduces every digit; 1v1 compares correctly positioned digits in the **same** number sequence. 20-second memorization + 30-second writing timer. |
| 8 | Missing Number | **Solo**: solve at least 6 of the 8 level-based number sequences correctly within the 150-second clock. |
| 9 | Clock Duel | **Solo**: all 6 time problems must be right within the 150-second clock. The existing beginner-level exclusion still applies. |
| 10 | Target Number | **1v1**: independently make an expression using the card numbers; active player scores only if closer to the target. Ties block points. |
| 11 | Reaction Rules | **1v1**: defender calls numbers; only the active player performs the rule-based actions. Zero action mistakes earns a point. |
| 12 | Alliteration Duel | **1v1**: make as many valid, distinct alliterative phrases as possible. Active player needs strictly **more** within 150 seconds. |
| 13 | Headline Challenge | **1v1**: each player writes a funny, maximum-ten-word headline for each situation. In a 3-player game the neutral third player judges; in a 2-player game both competitors decide together. Active player needs more winning situations; ties block the point. |
| 14 | Codebreaker | **Solo**: decode the level-dependent card alone and meet its existing level-dependent success target. |
| 15 | Count to Thirty | **1v1**: alternating runs of 1–3 consecutive numbers, active player beginning at one; existing level-adjusted end number and winner rule apply. No clock. |
| 16 | Rock-Paper-Scissors Council | **1v1**: no team consultation; five simultaneous throws. The active player must win more throws, otherwise no point. No main clock. |
| 17 | Alphabet Story | **1v1**: active player writes/says the A-sentence; defender B; alternate in order. Defender fails first → active scores. Active fails first OR the entire level-dependent story is completed → defender blocks the point. |
| 18 | Five Quick Facts | **Solo**: original cooperative game's five level-based questions become an individual challenge. Four correct out of five earn a point. |
| 19 | Quickfire Facts | **Solo or 1v1**: original six-question individual challenge; solo needs at least four correct, duel needs at least four correct **and more than defender**. |
| 20 | Trivia Board | **1v1**: each player answers a level-adjusted six-question card, and the current player scores only if they get more right. |

## Explicitly removed from Solo Showdown only

1. Sketch & Guess
2. Mime Relay
3. Silent Charades
4. Picture Race

These games remain selectable, fully functional and unchanged in **Team
Battles**. The shared difficulty-specific packs are not deleted.

## Details where a rule needed interpretation

1. **Two-player minimum:** “Up to three” could include one, but this version
   uses 2–3 so a challenger/opponent is always available, consistent with
   the pre-existing minimum of two teams.
2. **Three trivia games:** The feedback did not individually specify new
   rules for Five Quick Facts, Quickfire Facts or Trivia Board, so they keep
   the closest equivalent to their previous format: 4/5 solo, 4/6 solo or
   duel, and level-adjusted trivia duel respectively.
3. **Clock Duel solo success:** “If right then point” is implemented as
   solving **all six** questions; Missing Number keeps its existing 6/8
   success target. Both thresholds are printed on their cards.
4. **RPS Council tie handling:** Each of five throws can tie; only a total
   advantage in won throws grants the active player the point.
5. **Category Flood most-items:** The 1v1 variant is *not* subject to the
   fixed quota. Both competitors have the same category and 150 seconds.

## Regression checks

Automated tests cover: twenty available single games, four exclusions,
single-player roster limits, custom names, level-compatible matchups,
conditional solo/duel variants, game-card instructions, turn rotation,
points, per-level question-card availability and old Team Battles behavior.
