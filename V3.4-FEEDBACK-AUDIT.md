## Interpretations where the note used a different name

1. **“Sketch and copy”** was treated as **Shape Copy**, the name of the existing
   memory-copy drawing game. No separate Sketch & Copy game was added.
2. **“World recall”** was treated as **Word Recall Battle**.
3. **“Expert”** was treated as the highest, **Grandmaster**, proficiency.
4. **“a,b,c,d”** was interpreted literally at question level in all trivia
   formats, including mixed and normally open cards.

No other instructions required a guess that affected the rules of the game.

## Verification

- Automated tests cover question relocations, four-answer choices, math tiers,
  opponent level restrictions, category counts, target-number solvability,
  acting/drawing requirements, Codebreaker counts and timer resets.
- Legacy functionality has regression tests for points, turns, clocks, guest
  fullscreen, guest read-only controls, and five-device session limits.
